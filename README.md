# Algorithmic Credit Risk Modeling

## Project Overview
This project builds an AI-based credit risk prediction system for instant loan approval or denial.

## Features
- Chunk-based dataset loading
- SMOTE for handling imbalanced classes
- ElasticNet regularization model
- ROC-AUC analysis
- Optimal threshold selection
- Bank profit optimization

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Imbalanced-learn
- Seaborn
- Matplotlib
- Google Colab

## Machine Learning Techniques
- SMOTE
- ElasticNet
- ROC-AUC Curve
- Threshold Optimization
